# Example rulesystem packs (v2)

Generated by:

```bash
make rulesystem-examples
```

These JSON files are **not loaded** by thAImaturgy at runtime. Each is a
`rulesystem/v2` pack (~1300–2000 lines) describing attributes, workflows,
mechanics, oracle tools, rule chapters, and engine compatibility mappings.

| File | Lines | System |
|------|------:|--------|
| `dnd5e.json` | ~2000 | D&D 5e — 9 workflows, 21 tools, 4 chapters |
| `d100.json` | ~1300 | Percentile d100 / BRP — opposed checks, sanity |
| `savage_worlds.json` | ~1450 | SWADE — wild die, bennies, shaken/wounds |

Inspect a pack:

```bash
bin/rulesystem-gen -template dnd5e -inspect
```
