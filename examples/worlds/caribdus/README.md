# Caribdus

Self-contained nautical setting: storm-battered isles half-swallowed by the Deluge.

Colonial armadas, pirate republics, and sea-witch covens fight over reef-choked waters. Tone inspired by flooded-archipelago pulp (50 Fathoms / 50 Brazas).

## In this folder

- `world.json` — full catalog (ports, shoals, NPCs, bestiary, politics, world rules)
- Generated from `internal/worldpack/worlds/caribdus/pack.go`

## World rules (summary)

- **Magic:** Sea-witch hedge magic, cursed Deluge relics, tide-bound rituals
- **Technology:** Sailing age — flintlocks, schooners, diving bells
- **Politics:** Armada del Rey, Perla Azul republic, Capitanes Libres, Coven del Mar Espectral

## Rules at the table

Suggested: **Savage Worlds**. Also playable with D&D 5e or d100.

```bash
bin/worldpack-gen -template caribdus -inspect
# aliases: 50_brazas, 50_fathoms
```
