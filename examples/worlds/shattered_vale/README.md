# The Shattered Vale

Self-contained fantasy setting: river-valley city-states five years after the Shattering.

## In this folder

- `world.json` — full catalog (regions, cities, NPCs, bestiary, politics, world rules)
- Generated from `internal/worldpack/worlds/shattered_vale/pack.go`

## World rules (summary)

- **Magic:** Common — clerics, wizards, druidic rites; ley-line wild surges
- **Technology:** Late medieval — no gunpowder
- **Politics:** Merchants League, Order of the Dawn, Ironhold, Red Hand Bandits

## Rules at the table

Suggested: **D&D 5e**. Also playable with Savage Worlds or d100 — the world pack does not depend on a specific rulesystem.

```bash
bin/worldpack-gen -template shattered_vale -inspect
```
